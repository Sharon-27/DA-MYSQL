Views:
-------
A View is a virtual table created from the result of select query.
It doesn't normally stores the actual data separately instead it stores the SQL Query and
whenever you accesses the view, MySQL retrieves the data from the underlying tables.

Why do we need views?
Simplify complex queries.
Reuse query logic.
Data security.
Simplified reporting.


Advantages of views:
---------------------
Security
Simplicity
Reusability


Diff b/w table and view:
-------------------------
Table physically stores data
View is virtual table based on query.

Can stores records directly.
Usually doesn't store separate records.

Create using Create table
Create using create view.

It contain all table data.
Can show selected rows/columns.

Used for permanent data storage.
Mainly used for abstract, security, and reusable queries.

Create view Syntax
-------------------
create view view_name as
select column from table
where condition.

Altering view
---------------
alter view view_name as
select new_columns from new_tables
where new_conditions;

Drop a view
------------
drop view view_name;
